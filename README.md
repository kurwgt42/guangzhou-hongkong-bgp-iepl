## 为什么是"广州进 + 香港出"

IEPL（International Ethernet Private Line，国际以太网专线）和 IPLC 一样属于"端到端物理专线"，区别在于 IEPL 基于以太网接口，接入更灵活，端内延迟通常更低。广港 IEPL 指的就是入口在广东机房、出口在香港机房的一段以太网专线。

这个组合的吸引力来自两点：

- **端内只有 1–3ms 延迟**：广州到香港的物理距离短，全程几乎不绕路，本地 ping 这一段常常只有 2–4ms，对延迟敏感的业务非常友好。
- **入口侧的 BGP 多线**：广州入口如果是多线 BGP（如 UCloud 广州八线 BGP，覆盖电信、移动、联通、PCCW、GRET、NTT、Cogent、Lumen、Telstra、HE、Voxility 等），那国内三大运营商访问都不会绕到第三方骨干网。

代价是价格。IEPL 专线本身是按端口+流量计费的，比普通 BGP VPS 普遍贵一倍以上，所以讨论广港 IEPL，很大程度上是在讨论如何在够用的前提下挑一个合适的流量档位或带宽档位。

## 共享 vs 独享：怎么选

下面这套判断在多个独立测评里都能看到一致的结论，结合广港 IEPL 的实际情况可以直接拿来用：

1. **预算敏感、月流量可控**：选共享带宽版，按档位买流量就行。
2. **持续速率优先、不想被打断**：选独享带宽版，不限流量，预算上一个台阶但稳定性高。
3. **两边都想要**：通常不建议。共享带宽跑大流量会撞峰值；独享省心但贵，最终往往是两边都不到最优。

如果你只是需要一台机器做 Web 中转、跨境店铺独立 IP、TikTok ISP 关联，1TB（358 元）这档性价比最突出。如果要做 RDP / SSH 长期挂机或者多账号浏览器，2TB / 4TB 起步更稳。

## 常见 FAQ

**Q1：端内 3ms 和"用户实际延迟"是一回事吗？**
不是。3ms 是广州入口到香港出口这一段的端内延迟。真实用户访问这台机器，还要算上用户到广州入口这一段。华南用户通常 30–40ms 总延迟，华东 50ms 左右，华北 60–80ms，相比普通 BGP 香港线路有明显优势，但不会"全程 3ms"。

**Q2：必须实名吗？能不能换其他地区 IP？**
必须。所有 IEPL / IPLC 套餐都要求国内手机号 + 身份证 + 姓名一致性实名；面板只允许设置一个省份为入口白名单，不支持跨境变更。

**Q3：可以月付后再换套餐吗？**
可以升降级，但需要提交工单，差价按工单审核处理。开通后不支持更换到其他地域节点。

**Q4：共享带宽的 150Mbps 是不是随时能跑到？**
不是峰值保证。共享带宽是机房间的共享大管子，标称是高峰期可能接近的数值；晚高峰和不同目标节点都可能低于标称值。独享带宽才是真正承诺端口速率。

**Q5：用什么方式付款？**
支付宝为主，部分渠道也支持 USDT。商家在中国大陆注册主体，所以支付和实名是一套体系。
